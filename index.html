TriagePilot

Agentic incident triage with RAG over runbooks.

Four AI agents — a severity classifier, a log investigator, a RAG runbook retriever, and a remediation planner — triage outages end-to-end. Every step of the repair plan cites the exact runbook section it came from, and the planner refuses to guess when the evidence is thin.

  • Python
  • FastAPI
  • Hybrid retrieval
  • Eval harness

CodeCompass

Self-corrective multi-agent RAG for codebase Q&A.

Ask questions about a codebase in plain English. A planner retrieves candidate code, a critic judges whether the evidence actually answers the question and triggers a rewritten re-retrieval when it doesn't, and the synthesizer answers with file:line citations — or honestly abstains instead of hallucinating.

  • Python
  • AST-based indexing
  • FastAPI
  • Corrective RAG

14/14 tests · 100% answer hit-rate, citation precision, and abstention rate on a 14-case eval

SecureFlow

Ticket-to-PR secure SDLC pipeline.

A Jira-style requirement goes in and a Mermaid flow diagram comes out; then an automated security gate — secret scan, banned patterns, dependency deny-list, requirement completeness — runs on every pull request. When it finds issues, the PR fails and the full report is posted as a comment.

  • Python
  • GitHub Actions
  • Mermaid
  • DevSecOps

15/15 tests pass · gate demonstrably fails PRs on planted vulnerabilities

A11yGuard

UI vulnerability & accessibility remediation, before/after.

A demo storefront shipped in two versions: "before" carries 28 accessibility issues and 6 security findings, including a live XSS hole; "after" fixes all of them. Every fix is mapped to its WCAG 2.1 criterion in a remediation table, and automated checkers prove the difference in CI.

  • HTML/CSS/JS
  • Python checkers
  • WCAG 2.1
  • GitHub Actions

16/16 tests · before fails / after passes both checkers
